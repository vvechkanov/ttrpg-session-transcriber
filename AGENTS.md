# AGENTS.md

Транскрайбер сессий настольных RPG: PySide6/QML поверх шестислойного ядра
(`domain / sources / mergers / renderers / core / ui`). Правила зависимостей —
в [ARCHITECTURE.md](ARCHITECTURE.md).

## Commands

```bash
venv/Scripts/python.exe -m pytest -q -m "not slow and not requires_asr"
venv/Scripts/python.exe -m ruff check --select F821 .
```

Тесты с маркерами `slow` / `requires_asr` требуют GPU и весов моделей — в CI
не гоняются.

## Code Review Rules

Правила ниже выведены не из общих соображений, а из дефектов, реально
дошедших до master в этом репозитории. У каждого указано, чем он обернулся.

### Тест обязан вызывать продакшн-код

Флагуй тест, который повторяет логику проверяемого кода у себя вместо вызова
этого кода. Такой тест зелен, когда продакшн падает.

Было: тест фолбэка рендерера пересобрал `RENDERERS.get(name) or ...` внутри
себя. Настоящий фолбэк при этом звал необъявленный `logger`, ронял
`NameError`, и `merged.txt` не записывался вовсе. Тест был зелёный.

Флагуй так же тест, который сам подставляет значение, которое должен вычислить
продакшн-код: он скрывает, что продакшн его не вычисляет.

### Фича должна доходить до точки входа, которой служит

Флагуй код, добавленный в путь, которым заявленный потребитель не ходит.

В этом проекте **GUI не использует `core.pipeline`** — он идёт через
`PipelineController → MergerWorker`. CLI идёт через `core.pipeline.run`.
Вычисление, добавленное только в `core.pipeline` ради экрана, — мёртвый код.

Было дважды. Оба раза с зелёными тестами и смерженным PR.

### Сообщение об ошибке должно быть достижимо пользователю

Флагуй установку текста ошибки без перевода в состояние, в котором этот текст
отображается. `AppModel.errorMessage` рендерится только внутри `FailedBanner`,
привязанного к `phase === "failed"`.

Было: отказ запускать распознавание без установленной модели ставил сообщение
и выходил, не тронув фазу. Нажатие кнопки не делало ничего видимого.

### Отброшенные данные должны быть названы

Флагуй молчаливый отброс входных данных. Если события выкидываются как
неподходящие — это должно попасть в лог или в UI.

Было: 260 из 353 сообщений чата и целый бой отбрасывались как предшествующие
записи. Молча. Снаружи выглядело как «в транскрипте почему-то нет боёвки».

### Белый список имён, собираемых из данных, обречён отстать

Флагуй перечисление известных значений там, где источник конструирует имена из
входных данных. `CombatDumpSource` строит действия как `f"effect_{event_type}"`
— любой новый тип эффекта исчезнет из вывода.

Предпочитай «структура перечислена, остальное печатается как есть».

### UTC нельзя выдавать за местное время

Флагуй показ времени пользователю без разрешённого офсета сессии. Зона берётся
резолвером в `sources/game_log/fvtt_chat.py`; когда он говорит «не знаю»,
интерфейс обязан показать время от начала, а не подставить UTC или зону машины.

### Границы слоёв

`sources` импортирует только `domain`. `renderers` импортирует только `domain`.
`core → sources` разрешён. `domain` не импортирует ничего из проекта.
Флагуй нарушения, включая ленивые импорты внутри функций, обходящие правило.

### Чего не флагать

Форматирование, длину строк, порядок импортов — это дело линтера.
Русские комментарии и докстринги — здесь это норма, не дефект.
