# AGENTS.md

Транскрайбер сессий настольных RPG: PySide6/QML поверх шестислойного ядра
(`domain / sources / mergers / renderers / core / ui`). Правила зависимостей —
в [ARCHITECTURE.md](ARCHITECTURE.md).

## Commands

```bash
python -m pytest -q -m "not slow and not requires_asr"
python -m ruff check --select F821 .
```

Интерпретатор проекта — `venv/Scripts/python.exe` на Windows и
`venv/bin/python` на Linux и macOS. Команды выше записаны от активированного
окружения, чтобы работать одинаково на машине разработчика, в CI и в облачном
агенте.

Тесты с маркерами `slow` / `requires_asr` требуют скачанных весов моделей и
идут долго — поэтому в CI не гоняются. GPU не обязателен: `requires_asr`
настроены на CPU (`device="cpu"`, `compute_type="int8"`).

## Code Review Rules

### Тест обязан вызывать продакшн-код

Флагуй тест, который повторяет логику проверяемого кода у себя вместо вызова
этого кода.

Флагуй тест, который сам подставляет значение, которое должен вычислить
продакшн-код.

Безопасный путь: тест зовёт публичную функцию или воркер целиком и проверяет
то, что тот вернул.

### Фича должна доходить до точки входа, которой служит

Флагуй код, добавленный в путь, которым заявленный потребитель не ходит.

GUI идёт через `PipelineController → MergerWorker`. CLI идёт через
`core.pipeline.run`. Вычисление, добавленное только в `core.pipeline` ради
экрана, до экрана не доедет.

Безопасный путь: назвать цепочку вызовов от действия пользователя до нового
кода.

### Сообщение об ошибке должно быть достижимо пользователю

Флагуй установку текста ошибки без перевода в состояние, в котором этот текст
отображается. `AppModel.errorMessage` рендерится только внутри `FailedBanner`,
привязанного к `phase === "failed"`.

Безопасный путь: вместе с текстом выставляется фаза, в которой он виден.

### Отброшенные данные должны быть названы

Флагуй молчаливый отброс входных данных: событий, сообщений чата, дорожек,
файлов.

Безопасный путь: количество и причина попадают в лог или в отчёт о покрытии.

### Белый список имён, собираемых из данных, обречён отстать

Флагуй перечисление известных значений там, где источник конструирует имена из
входных данных. `CombatDumpSource` строит действия как `f"effect_{event_type}"`.

Безопасный путь: перечислять то, что обрабатывается особым образом, а остальное
печатать как есть.

### UTC нельзя выдавать за местное время

Флагуй показ пользователю абсолютного времени без офсета, разрешённого
резолвером в `sources/game_log/fvtt_chat.py`.

Безопасный путь: когда резолвер не смог определить зону, показывать время от
начала записи, а не подставлять UTC или зону машины.

### Границы слоёв

`sources`, `mergers` и `renderers` импортируют только `domain` — и никогда
друг друга. `core` может импортировать все четыре. `ui → core`. `domain` не
импортирует ничего из проекта. Полный список — в
[ARCHITECTURE.md](ARCHITECTURE.md), секция «Dependency rules».

Флагуй нарушения, включая ленивые импорты внутри функций, обходящие правило.

### Чего не флагать

Форматирование, длину строк, порядок импортов — это дело линтера.
Русские комментарии и докстринги — здесь это норма, не дефект.
